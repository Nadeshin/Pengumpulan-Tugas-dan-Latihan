### Kasus 5 — ADT Structure vs typedef

> 📂 [`PAS1_Kasus5_A11.2026.16980`](PAS1_Kasus5_A11.2026.16980) · 🎯 Tipe bentukan + eksperimen alias · 📈 `2 File C++` + `1 Dokumen`

```cpp
struct nilai { int x; int y; };   // versi struct  →  struct nilai n1;
```

Output keduanya: `23`. Bedanya dibedah tuntas di [`Analisis struct vs typedef.docx`](PAS1_Kasus5_A11.2026.16980/Analisis%20struct%20vs%20typedef.docx) — typedef hanya memberi nama alias sehingga deklarasi lebih ringkas, isi & memori identik.

### Kasus 7 — Latihan Pointer

> 📂 [`PAS1_AnalisisKasus7_A11.2026.16980`](PAS1_AnalisisKasus7_A11.2026.16980) · 🎯 Pointer & alamat memori · 📈 `1 File C++` + `1 Dokumen`

```cpp
int i = 15, *p, *q;
p = &i; *p = 20;   // i → 20
i = 50;            // *p ikut 50
q = &i; *q = 100;  // i = *p = *q = 100, p == q
```

```text
Nilai i: 20 → 50 → 100 · Nilai *p: 50 → 100 · Nilai *q: 100
Alamat p == Alamat q (satu memori yang sama dengan i)
```

Analisis 3b lengkap: [`PAS1_AnalisisKasus7_A11.2026.16980.docx`](PAS1_AnalisisKasus7_A11.2026.16980/PAS1_AnalisisKasus7_A11.2026.16980.docx)
